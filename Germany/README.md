# Немецкий выход через собственный WireGuard VPS

Для немецкого IP нужен VPS с публичным IPv4 и IPv6 в немецком дата-центре. Аренда VPS оплачивается отдельно. Этот комплект не создаёт сервер автоматически: он подготавливает настройку, которую владелец VPS запускает на сервере.

## Настройка сервера

Поддерживаются свежие образы Debian и Ubuntu. У VPS должны быть публичные IPv4 и IPv6, IPv6-маршрут по умолчанию и возможность открыть входящий UDP-порт 51820 в панели провайдера. Скрипт отказывается создавать IPv4-only туннель, чтобы IPv6-трафик компьютера не пошёл напрямую через исходную сеть.

Скопируй папку `Germany` на VPS, подключись по SSH и выполни:

```bash
sudo bash setup-wireguard-server.sh <ПУБЛИЧНЫЙ_IPV4_VPS>
```

Скрипт установит WireGuard, создаст ключи сервера и клиента, включит IP forwarding, настроит NAT для IPv4 и IPv6 и включит запуск туннеля после перезагрузки. Настройки сервера пишутся в `/etc/wireguard/wg0.conf`, клиентский профиль — в домашнюю папку SSH-пользователя с правами только для владельца.

Открой UDP 51820 в firewall панели VPS. Если меняешь порт, передай его вторым аргументом скрипта и открой тот же порт у провайдера.

## Подключение Windows

Установи официальный [WireGuard для Windows](https://www.wireguard.com/install/) и скопируй `bonny-germany-client.conf` с VPS на компьютер. В GUI нажми «Импорт .conf» и выбери файл; в CMD запусти `Run-Bonny.cmd germany` и выбери пункт 9. Мастер попросит имя профиля, безопасно сохранит конфиг и начнёт подключение; Windows может запросить права администратора. Можно также выполнить `Run-Bonny.cmd germany-setup`, чтобы выбрать файл из CMD, или передать путь к нему командой `Run-Bonny.cmd germany-setup "C:\путь\к\профилю.conf"`. Для нескольких профилей используй разные имена и выбери активный в CMD-меню.

Файл содержит приватный ключ клиента: оставь его на своём компьютере и никому не отправляй. Bonny сохраняет импортированные профили в `%LocalAppData%\Bonny` с ограниченными правами доступа. Мастер подключает уже настроенный VPS, но не покупает, не арендует и не настраивает сервер автоматически.

Профиль направляет IPv4- и IPv6-трафик, включая UDP и QUIC, через VPS. В меню можно подключить, переподключить и отключить выбранный профиль; одновременно Bonny не запускает несколько своих полнотуннельных профилей. Пункт «Включить автоподключение при запуске Windows» запускает выбранную службу при загрузке компьютера и настраивает Windows перезапускать службу после сбоя. Для этого нужны права администратора. Отключить автозапуск можно отдельным пунктом меню; сменить профиль при включённом автозапуске можно после его выключения.

Kill switch не включён. Если служба остановлена, трафик может пойти через обычное подключение; если VPN-сервер или протокол блокируется сетью, автозапуск не сможет восстановить доступ. Перезапуск службы помогает только при её сбое и не подтверждает WireGuard handshake или доступность интернета через VPS. Проверяй соединение отдельно и отключай автозапуск, если он больше не нужен.

Когда туннель включён и VPS настроен правильно, сайты видят адрес выхода VPS; фактическую страну выхода определяет его дата-центр. Это отдельный VPN-туннель, а не функция DPI-пересегментации Bonny. Пока профиль не установлен и туннель не подключён, IP не изменится.

## Отключение сервера

На VPS отключить и удалить автозапуск можно так:

```bash
sudo systemctl disable --now wg-quick@wg0
```

Это отключает серверный WireGuard-интерфейс, но не отменяет оплату аренды VPS.
